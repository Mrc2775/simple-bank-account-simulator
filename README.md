# Bank Account Simulator

A Python project that simulates basic bank account operations.

## Features
- Create account
- Deposit money
- Withdraw money
- Check balance
- Save transactions into a CSV file

## Skills Used
- Python
- OOP
- File handling
- Dictionaries
- Loops and conditionals

## Project Goal
This project was made to practice Python fundamentals and object-oriented programming in a simple project.

##Future Improvements
- Add multiple account support with saved data
- Add PIN/password protection
- Add transfer between accounts
- Save account data permanently in JSON
